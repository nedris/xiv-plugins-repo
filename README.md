# Nedris' XIV plugins — Dalamud repository

Custom plugin repository for Dalamud (FINAL FANTASY XIV).

In game: `/xlsettings` → **Experimental** → **Custom Plugin Repositories**, add

```
https://raw.githubusercontent.com/nedris/xiv-plugins-repo/main/repo.json
```

save, then install from the plugin installer.

| Plugin | What it does |
|---|---|
| **Waypoint** | Searchable teleport menu (EN/FR) replacing the vanilla one: favorites, housing, friends' estates. |
| **Proximity** | Nearby players + who is targeting you + emote log, in one window. |
| **Sync Priority** | Keeps only Lightless Sync for players synced by both Lightless Sync and Player Sync. |
| **Kinship** | Modern friend list replacing the vanilla one: live online status, groups, friendship length, last seen, notes, estate teleports. |

This repository only holds the built plugins (`plugins/<Name>/latest.zip`) and `repo.json`; it is generated by `publish.ps1` in the source repository.
